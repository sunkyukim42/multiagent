# Project Limitations

## Single Source Of Truth

These limitations apply to the offline benchmark, research-evaluation tables,
portfolio materials, and final package.

## Data Limitations

- The cases are synthetic and illustrative.
- The sample size is tiny.
- Fixed expert labels are not yet available.
- Domain coverage is limited to sample oil and procurement scenarios.

## Method Limitations

- Methods are offline illustrative variants.
- Retrieval uses local sample documents and deterministic scoring.
- Heuristic groundedness is not semantic entailment.
- Route decisions are useful for review planning, not operational approval.

## Evaluation Limitations

- The package is not paper-ready.
- The results are not statistically conclusive.
- Repeated seeds and statistical tests need larger labeled datasets.
- Human/expert evaluation remains future work.

## Use Limitations

- No financial/procurement/legal advice.
- No production deployment, PDF, PowerPoint, interactive UI, or live API integration
  is included.
- The live `python main.py` path remains separate from this offline package.
