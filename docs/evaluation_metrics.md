# Evaluation Metrics

Task 8 summarizes metrics generated by the offline Reliability Guardrails. These metrics are deterministic heuristics for sample demonstrations, not legal, financial, or procurement judgments.

| Metric | Definition |
| --- | --- |
| Citation coverage | Linked claims divided by total claims. |
| Temporal leakage rate | Claims linked to evidence that is future-published or not yet effective relative to the decision date. |
| Heuristic grounded claim rate | Claims classified as grounded by lexical/keyphrase overlap with linked snippets or text. |
| Unsupported claim rate | Claims classified as unsupported or with no evidence. |
| Policy compliance rate | Policy rules passed divided by policy checks considered. |
| Calculation traceability | Numeric claims whose numbers can be traced in linked snippets or text. |
| Consistency warning rate | Warning count for conservative contradiction checks divided by relevant claim count when available. |
| Overall score | Weighted aggregate from the guardrail pipeline configuration. |
| Route counts | Counts of workflow routes: `final_report`, `retry`, `human_review`, and `stop`. |

Heuristic groundedness is not semantic entailment. A high score means the offline checks found fewer deterministic issues; it does not mean the recommendation is correct.
